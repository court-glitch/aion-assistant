# Aion AI Assistant

**AION – AI Workplace Productivity Assistant**  

**Tagline:** Your Intelligence, Accelerated.

**Brand Summary for Lovable AI (Free Account – 5 Tokens)**

**Product**  

AION is a modern, clean, professional SaaS-style dashboard that helps professionals automate workplace tasks with AI. Uses indigo (#1E1B4B, #4F46E5), vibrant violet (#8B5CF6), and black (#0B0B0E) palette. Fixed sidebar with professional geometric logo (stylized robot head with glowing indigo eyes in front of a sleek laptop with violet keyboard lines, inside a dark rounded badge, next to bold white “AION” text). All outputs are editable, structured AI prompts drive every tool, and a clear Responsible AI disclaimer appears on every screen.

**Layout & Design**  

- Sidebar (280px fixed on desktop): Logo at top, navigation items with icons (Dashboard, Smart Email Generator, Meeting Notes Summarizer, AI Task Planner, AI Research Assistant), divider, then Settings + AI Usage Meter + Quick Tip Carousel.  

- Main area: Fluid 12-column grid, max 1440px. Glass-morphism cards with Soft Indigo borders. 24px spacing.  

- Responsive: Desktop full sidebar, tablet hamburger, mobile bottom nav.  

- No user profile or database.

**Key Features**  

1. **Smart Email Generator** – Input: Recipient, Subject Context, Key Points, Tone (Formal/Friendly/Persuasive), Length slider. Output: Editable rich-text email.  

2. **Meeting Notes Summarizer** – Paste/upload notes + context + duration. Output: Executive summary, Key Decisions, Action Items table (editable), Deadlines.  

3. **AI Task Planner** – Input: Role, Workload, Top Priorities, Daily/Weekly toggle. Output: Calendar view with drag-and-drop prioritized tasks.  

4. **AI Research Assistant** – Input: Topic/URL, Focus Area, Depth. Output: Summary, Insights, Recommendations, Citations.

**Core UX Rules**  

- Every AI output is in a rich-text editor (click to edit).  

- Buttons: Copy, Regenerate, Insert Variables, Export.  

- Tip: “Click any generated text to edit — saved locally.”  

- Responsible AI disclaimer fixed at bottom of every feature page.  

- Empty states, loading (“AION is thinking…”), and error states defined.  

- Quick Action buttons on Dashboard lead directly to each tool.
